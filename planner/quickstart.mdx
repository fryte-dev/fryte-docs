## 1. Submit your route

<Info>
You need an [API key](/#authentication) and a [Vehicle ID](/planner/vehicles).
</Info>

<Warning>
For truck routing, always set `poi_info.truck_approved` (`"T"` or `"TT"`). Without it the
optimizer considers every charger that matches power and connector — including urban stations a
truck cannot physically access. See
[Always set the truck-ready filter](/planner/examples/search-corridor#always-set-the-truck-ready-filter).
</Warning>

<CodeGroup>
```bash curl
curl -X POST "https://api.fryte.com/planner/v2" \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "vehicle_id": "010160700001",
    "battery_level_start": 0.8,
    "section_list": [
      {
        "start_pos": [48.7758, 9.1829],
        "stop_pos": [52.5200, 13.4050],
        "payload_kg": 19300
      }
    ],
    "poi_info": {
      "min_kW": 150,
      "connector_type": ["CCS"],
      "truck_approved": "TT"
    }
  }'
```
```python Python
import requests

response = requests.post(
    "https://api.fryte.com/planner/v2",
    headers={"Authorization": "Bearer <your-token>"},
    json={
        "vehicle_id": "010160700001",
        "battery_level_start": 0.8,
        "section_list": [
            {
                "start_pos": [48.7758, 9.1829],
                "stop_pos": [52.5200, 13.4050],
                "payload_kg": 19300,
            }
        ],
        "poi_info": {
            "min_kW": 150,
            "connector_type": ["CCS"],
            "truck_approved": "TT",
        },
    },
)
print(response.json())
```
```javascript JavaScript

    },
  }),
});

console.log(data);
```
```csharp C#
using var client = new HttpClient();
client.DefaultRequestHeaders.Add("Authorization", "Bearer <your-token>");

var json = """
{
    "vehicle_id": "010160700001",
    "battery_level_start": 0.8,
    "section_list": [
        {
            "start_pos": [48.7758, 9.1829],

    }

    "https://api.fryte.com/planner/v2",
    new StringContent(json, System.Text.Encoding.UTF8, "application/json")
);
var result = await response.Content.ReadAsStringAsync();
Console.WriteLine(result);
```
</CodeGroup>

The API starts optimizing in the background and returns identifiers to track the job.

```json

  "tour_id": 7673
```

## 2. Check progress

Poll with your `job_id` until `status` is `succeeded`.

<CodeGroup>
```bash curl
curl "https://api.fryte.com/planner/jobs/<job_id>" \
  -H "Authorization: Bearer <your-token>"
```
```python Python
import requests

response = requests.get(
    "https://api.fryte.com/planner/jobs/<job_id>",
    headers={"Authorization": "Bearer <your-token>"},
)
print(response.json())
```
```javascript JavaScript
const response = await fetch("https://api.fryte.com/planner/jobs/<job_id>", {
  headers: {
    "Authorization": "Bearer <your-token>",
  },
});
const data = await response.json();
console.log(data);
```
```csharp C#
using var client = new HttpClient();
client.DefaultRequestHeaders.Add("Authorization", "Bearer <your-token>");

var response = await client.GetAsync("https://api.fryte.com/planner/jobs/<job_id>");
var result = await response.Content.ReadAsStringAsync();
Console.WriteLine(result);
```
</CodeGroup>

```json
{
  "status": "succeeded",
  "optimization_id": 7716,
  "job_id": "20ccaf8b-d36b-4c21-bb32-d00e758abe14",
  "tour_id": 7673,
  "vehicle_id": "010160700001"
}
```

<CodeGroup>

## General

**Single Route Only:** The API evaluates exactly one route per request and does not generate or compare alternatives. This applies whether you pass start/stop coordinates for automatic routing or provide a custom flexpolyline.

**Battery Constraints:** State of Charge (SoC) must be 0.1–1.0 at departure and 0.1–0.8 at arrival.

**Search Corridor:** Station searches are restricted to a 1–20 km radius around the route (default: 8 km) — see [Search Corridor](/planner/examples/search-corridor).

**Truck accessibility:** The station database contains chargers of all kinds. Only stations flagged `truck_approved` (`T` / `TT`) are verified for truck access — [always set this filter](/planner/examples/search-corridor#always-set-the-truck-ready-filter) for truck requests.

## Charging stops

**Short stops by default:** The optimizer minimizes total tour time and may plan short "bridge" charges of only a few minutes when that is time-optimal. Set [`min_charge_duration_min`](/planner/examples/minimum-charge-duration) (0–100 minutes) to enforce a floor on charging session length.

**Overnight charging:** During the mandatory 11-hour overnight rest, `charge_time_min` reports the full overnight stay, not only the effective plugged-in charging time.

## Rate Limits

Each endpoint allows **120 requests per minute** per client IP. Requests exceeding this limit receive a `429 Too Many Requests` response.

## Vehicles

Only pre-configured vehicles are supported. You cannot submit custom vehicle specifications — use the [Vehicle ID lookup](/planner/vehicles) to find your vehicle. The vehicle database is managed by FRYTE.

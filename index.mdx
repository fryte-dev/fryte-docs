The FRYTE Planner API optimizes routes for electric trucks. Submit a route, and the API returns an optimized plan with charging stops, battery levels, energy consumption, and toll costs — ready to integrate into your TMS.

## Base URL

```
https://api.fryte.eu
```

## Authentication

All requests require a Bearer token in the `Authorization` header:

```
Authorization: Bearer <your-token>
```

Contact us at [team@fryte.eu](mailto:team@fryte.eu) to obtain your API key.

## How it works

The API is asynchronous. Three steps:

<Steps>
  <Step title="Submit a route">
    `POST /planner/v2` — returns a `job_id` and `optimization_id` (HTTP 202).
  </Step>
  <Step title="Poll for completion">
    `GET /planner/jobs/{job_id}` — repeat until status is `succeeded`.
  </Step>
  <Step title="Retrieve the result">
    `GET /planner/optimizations/{optimization_id}/result` — the optimized route with charging stops, battery levels, and toll costs.
  </Step>
</Steps>
